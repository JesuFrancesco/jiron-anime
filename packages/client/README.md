# Jirón Anime

## Requisitos

- flutter
- [.env](.env) completo con los parámetros señalados en el [.env.example](.env.example)
- las credenciales de android en [android/app/janime.jks](android/app/janime.jks) y en [app/key.properties](android/key.properties) verificadas

## Comando de ejecución

```sh
flutter run --dart-define-from-file .env
```
